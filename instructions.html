Como enviar os trabalhos

📝 Texto

Use esta opção para enviar o texto do trabalho (tema: "Quem é o intelectual para você?"). Escreva no campo de texto no formulário.

🖼️ Foto

Use para enviar mapas mentais ou mapas semânticos. Selecione a imagem do dispositivo no campo de envio.

▶️ Vídeo

Envie o vídeo ao YouTube (configuração "Não listado") e cole o link no campo indicado. Esse vídeo corresponde ao podcast.

👥 Seleção dos estudantes

Selecione o(s) aluno(s) que participaram. Para trabalhos em grupo, adicione todos os integrantes.

⏳ Aprovação

Os trabalhos enviados ficam pendentes até aprovação por um administrador. Apenas administradores podem Aprovar/Editar/Apagar.
