Instruções

Confira abaixo como enviar cada tipo de trabalho para a Revista Digital.

📝 Texto

Esta parte deve ser utilizada para colocar o texto do primeiro trabalho realizado em sala de aula, sobre o tema “Quem é o intelectual para você?”. Escreva o trabalho diretamente no campo disponibilizado no momento da publicação.

🖼️ Foto

Esta opção deve ser utilizada para publicar o trabalho do mapa semântico ou mapa mental. Selecione a imagem diretamente no seu dispositivo e ela será enviada para o armazenamento da Revista Digital.

▶️ Vídeo

Para publicar o vídeo, primeiro envie o vídeo para o YouTube. O vídeo deve estar configurado como “Não listado”. Depois, coloque o link do vídeo no campo indicado. Esse vídeo corresponde ao trabalho do podcast.

👥 Seleção dos estudantes

Ao enviar um trabalho, é necessário selecionar o nome do estudante que realizou a atividade.

Caso o trabalho tenha sido realizado em grupo, selecione o nome de todos os integrantes utilizando o botão para adicionar outro aluno.

Isso é importante para que o trabalho seja contabilizado corretamente nas estatísticas de cada estudante.

⏳ Aprovação dos trabalhos

Depois de enviado, o trabalho não aparecerá imediatamente na página principal.

Ele será enviado para análise e aprovação por alguém da administração da Revista Digital.

Somente depois de aprovado o trabalho ficará disponível publicamente na página.
